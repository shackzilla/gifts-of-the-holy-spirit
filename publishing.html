WEBSITE OWNER’S GUIDE

Publish & update your study

This is a complete static website. The package includes the study pages, styles, diagrams, cover image, and downloadable version 1.2 PDF. It needs no database or build step.

Share the hosted website

If you are using the published ChatGPT Site, share its web address with readers. You can place that link on your church website, in a group message, or in a social post. To revise that version, return to this conversation with the changes or an updated study document.

Publish your own copy with GitHub Pages

GitHub Pages supports public repositories on GitHub Free. These instructions use a separate project repository so this study can have its own address.

  1. Download Gifts_of_the_Holy_Spirit_Website.zip. In Windows, right-click it and select Extract All. Open the extracted folder. You should see index.html, study HTML files, the assets folder, and the PDF.
  2. Sign in at github.com. Click the + menu, then New repository. Name it gifts-of-the-holy-spirit, select Public, enable Add README, and click Create repository.
  3. Open the repository’s Code tab. Select Add file → Upload files. Drag the extracted files and the entire assets folder into the upload area. Upload their contents at the repository root, not the enclosing extracted folder. Do not upload only the ZIP.
  4. Scroll down, enter a message such as Add Bible study website, then click Commit changes. Confirm that index.html is visible directly in the repository and that the assets folder contains the images, CSS, and JavaScript.
  5. Go to Settings → Pages. Under Build and deployment, choose Deploy from a branch. Select main and /(root), then click Save.
  6. Wait for GitHub’s deployment to finish. Return to Settings → Pages and use the published address shown there. A project site’s address normally follows https://YOUR-USERNAME.github.io/gifts-of-the-holy-spirit/.
  7. Open the address on both your computer and phone. Check a study page, a table, a diagram, and Download PDF, then share the address with your readers.

The .nojekyll file in the ZIP allows direct static publishing. Windows may omit this file from a drag-and-drop selection; this website also uses ordinary filenames compatible with GitHub’s default processing.

Make changes later

Each study is a separate HTML file. For example, wisdom is in wisdom.html. To edit a small passage on GitHub, open that file, click the pencil icon, locate the passage, edit only its text, and commit the change. GitHub Pages republishes changes committed to the selected branch.

For larger revisions, ask for an updated website package, then upload the replacement files. If the PDF changes, replace gifts-of-the-holy-spirit.pdf too. Search uses assets/search-index.js; refresh that file along with any edited study text. The stylesheet is assets/style.css.

Preview before uploading

Open index.html from the extracted folder in your browser. Navigation, images, and course search work locally. Keep all the files and the assets folder together.

If something does not look right

  • Page not found: check that Pages uses main and /(root), and that index.html is at that root. Check the repository’s Actions tab for a failed deployment.
  • Missing colors or images: confirm the entire assets folder was uploaded and its spelling and letter case match the file links.
  • Old text after an update: wait for the latest deployment, then refresh with Ctrl+F5.
  • PDF will not download: confirm gifts-of-the-holy-spirit.pdf is beside index.html.
