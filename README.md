# Gifts of the Holy Spirit — Bible Study Website

Open index.html to preview the site. Read publishing.html for full Windows and GitHub Pages instructions.

Upload all these files, including assets/, to the root of a public GitHub repository. In Settings → Pages select Deploy from a branch, main, /(root), then Save.

Source: The Gift of Wisdom Bible Study V.1.2.docx.pdf. Eight studies cover the nine gifts listed in 1 Corinthians 12:8–10. The original content, tables and embedded diagrams are retained.

Edit the individual .html study files. Update assets/search-index.js to keep search synchronized. Replace gifts-of-the-holy-spirit.pdf when the book is updated.

No external fonts, analytics, form submissions, or backend dependencies. All assets are included.
